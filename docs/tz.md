# ТЗ: Тестовое задание на должность «Фронтенд разработчик React»

Источник: `docs/task/*.png` (3 скриншота задания). Ниже - дословная выжимка.
Заполнено, чтобы держать требования перед глазами и сверять сдачу.

## Задача

Разработать пользовательский интерфейс для **отправки и получения сообщений в
MAX**. Если для MAX выполнить невозможно - допускается **WhatsApp или Telegram**.

**Время на выполнение: 5 дней.**

## Требования

1. Пользовательский интерфейс для отправки и получения сообщений в MAX.
2. Использовать сервис **GREEN-API** (https://green-api.com/max).
3. Отправка и получение **только текстовых** сообщений.
4. За прототип интерфейса взять внешний вид чата **https://web.max.ru/**.
5. Интерфейс **максимально простой**, минимальный набор функций.
6. Отправку реализовать методом **SendMessage**
   (https://green-api.com/v3/docs/api/sending/SendMessage/).
7. Получение реализовать методом/технологией **HTTP API**
   (https://green-api.com/v3/docs/api/receiving/technology-http-api/) -
   то есть `ReceiveNotification` + `DeleteNotification`.
8. Использовать технологию **React**.

## Ожидаемый результат (сценарий)

- Пользователь заходит на сайт чата и вводит свои учётные данные из GREEN-API
  (`idInstance`, `apiTokenInstance`).
- Вводит номер телефона получателя и создаёт новый чат.
- Пишет текстовое сообщение и отправляет его получателю.
- Получатель отвечает в мессенджере.
- Пользователь видит ответ получателя в чате.
